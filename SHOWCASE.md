# Fork Hall of Fame

Anyone who forks this repo and completes days can add one row below. This
is the wall of people who did the work, not just starred the repo.

| GitHub username | Days completed | Favorite algorithm |
| --- | --- | --- |
| _Your row goes here. See the template below._ | | |

## Row template

Copy this line into the table, fill it in, and open a PR:

```
| @your-username | 7 | kmeans |
```

- GitHub username: your handle, with the `@`.
- Days completed: how many days you finished (workbook filled in, self-check
  green). Be honest: 3 finished days beats 7 skimmed ones.
- Favorite algorithm: the one you learned the most from.

## PR instructions

1. Fork the repo (if you have not already).
2. Edit this file: add your row to the table, keeping the table sorted by
   username is not required. Just append your row.
3. Open a PR titled `Showcase: @your-username`.
4. In the PR body, write one line per completed day, or just the day count
   if you prefer. No proof required, but honest rows only.

Maintainers merge showcase PRs as long as the row follows the template.
